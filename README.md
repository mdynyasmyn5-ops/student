# نظام إدارة وتحليل نتائج الطلاب

برنامج بسيط يعمل من الـ Console بلغة JavaScript لتحليل نتائج الطلاب وتطبيق لجنة الرأفة على المتعثرين.

## المميزات

- حساب متوسط درجات كل طالب باستخدام `reduce`
- تحديد التقدير (A – F) حسب المتوسط
- تحديد النتيجة النهائية: المتوسط ≥ 50 والحضور ≥ 75% → **ناجح**، غير ذلك → **يحتاج مراجعة**
- لجنة الرأفة:
  - `filter`: استخراج الطلاب ذوي المتوسط بين 40 و 49
  - `map`: إضافة 5 درجات رأفة
  - `reduce`: جمع المتوسطات الجديدة وحساب المتوسط العام (مع حماية من القسمة على صفر)

## التشغيل

يلزم تثبيت [Node.js](https://nodejs.org).

```bash
node students.js
```
